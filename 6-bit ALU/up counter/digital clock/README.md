# Digital Clock using Verilog

## Description

This project implements a 24-hour digital clock using Verilog HDL.

The clock displays time in the format:

HH:MM:SS

The clock automatically increments seconds, minutes, and hours.

## Features

- 24-hour format
- Seconds counter: 00-59
- Minutes counter: 00-59
- Hours counter: 00-23
- Automatic rollover
- Reset functionality
- Synthesizable Verilog RTL
- Simulation testbench included
